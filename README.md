# Mon View

Trình xem ảnh nhanh cho Windows: PNG, JPG, GIF (cả GIF động), WEBP, ICO, BMP, PSD, PSB, TGA, TIFF.

**Tải về:** vào [Releases](https://github.com/satthupc00/M-View/releases/latest), tải `MonView-Setup-x.y.z.exe` rồi chạy. App tự báo khi có bản mới.

| Thao tác | Phím / chuột |
|---|---|
| Ảnh trước / sau | ← → hoặc lăn chuột |
| Zoom | + − hoặc Ctrl + lăn chuột |
| 1:1 ⇄ vừa khung | Ctrl+0 hoặc double click |
| Phóng ảnh vừa khung app | Giữ chuột trái + bấm chuột phải |
| Toàn màn hình | Chuột giữa (Esc để thoát) |
| Menu lệnh | Chuột phải |
| Nền caro / đổi màu nền | A / B |
| Xoay 90° | Ctrl+← / Ctrl+→ (hoặc R / Shift+R) |
| Mở cửa sổ mới | Chuột phải file trong Explorer → "Mở bằng Mon View (cửa sổ mới)", hoặc Ctrl+N |
